# Continuous Smart Play: one unlisted Energy Ball trial

This trial uses the current compact controls with one native audio element.
Original uses the existing public 0.3.0 MP3 or FLAC based on site preference.
Resonant Tuning Off uses a complete pre-encoded stereo MP3 with no runtime
media switching at the edit. This does not change the normal player, release,
catalog, or prior Comfort experiment. No private input, new narration, WAV
master, service worker, external service, or audio file commit is involved.

The production build positively verifies the exact public MP3 and timed-text
digest, checks speech-free cut margins, renders a 500 ms stereo crossfade,
validates the audio parameters and duration, then inventories the output.
The page is noindex, unlinked and outside the sitemap. It is public to anyone
with the link, not access restricted. This trial does not contain the full
Smart Play option set.

Use the gear to choose Off. Press Play, then the bookmark to start fifteen
seconds before the transition. Lock the device or switch apps and listen for
continuity into the Energy Ball guidance. Desktop and phone-emulation tests
do not prove Android behavior with the physical screen locked.
