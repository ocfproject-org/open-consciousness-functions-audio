# Get involved

OCF is open source. You can help make the practices easier to understand, the
website easier to use and the material available to more people.

## Suggest a function improvement

Each function page has a **Propose an edit** link to that function's canonical
English YAML resource on GitHub. YAML is a structured text file containing the
function's content and metadata. Explain what you want to change and why in a
pull request; the project reviews proposals before they become a published guide
or recording. Editing a source file does not replace an existing audio release.

Read the [contribution guide](https://github.com/ocfproject-org/open-consciousness-functions/blob/main/CONTRIBUTING.md)
before submitting. If you prefer not to edit files, [open a source-project issue](https://github.com/ocfproject-org/open-consciousness-functions/issues)
with the function name, the passage and your suggested improvement.

## Help translate

Start with the [locale overview](https://github.com/ocfproject-org/open-consciousness-functions/blob/main/locales/README.md)
and [localization guide](https://github.com/ocfproject-org/open-consciousness-functions/blob/main/docs/LOCALIZATION.md).
Keep function and command identifiers intact, and follow the project's review
process for translated cues and instructions. Translation drafts need language
review before being presented as reviewed material.

## Improve the website

Report confusing navigation, accessibility problems or incorrect links in the
[website issue tracker](https://github.com/ocfproject-org/open-consciousness-functions-audio/issues).
Include the page address, your device and browser, and what you expected to
happen. Code contributions go to the
[audio website repository](https://github.com/ocfproject-org/open-consciousness-functions-audio).

## Share ideas for future listening

Guided meditations and connected series are planned. Tell us what kind of
session, theme or learning journey you would find useful. You can send feedback
below or suggest an idea in the source-project issue tracker.
